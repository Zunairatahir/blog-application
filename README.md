# Responsive Blog Application
A Blog Application developed using HTML, CSS and JavaScript as part of my Codomax Digital Full Stack Web Development Internship.

## Features

- Responsive homepage
- Featured blog section
- User registration page
- User login page
- User dashboard
- Create Blog page
- Blog categories
- Form validation
- LocalStorage-based user registration and login
- LocalStorage-based blog data storage
- Responsive design for desktop, tablet, and mobile devices
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
