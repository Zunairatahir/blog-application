# Blog Platform

A modern and responsive blog application frontend developed using HTML, CSS, and JavaScript as part of my Full Stack Web Development Internship at Codomax Digital.

## Project Overview

Blog Platform is a responsive blogging interface designed to provide users with a simple and clean experience for exploring blogs, creating an account, logging in, managing blog content, and publishing new posts.

This project focuses on the frontend development phase of a full-stack blog application.

## Features

- Responsive homepage
- Featured blog section
- User registration page
- User login page
- User dashboard
- Create Blog page
- Blog categories
- Form validation
- LocalStorage-based user registration and login
- LocalStorage-based blog data storage
- Responsive design for desktop, tablet, and mobile devices
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

## Pages

### Home
Introduces the platform and displays featured blog posts.

### Register
Allows new users to create an account.

### Login
Allows registered users to log in using their credentials.

### Dashboard
Provides an overview of the user's blog activity, including blog statistics and recent posts.

### Create Blog
Allows users to create and publish a blog post by entering a title, category, and content.
